# Atas de Reunião e Decisões

## 1. Objetivo

Registrar as reuniões, decisões e definições realizadas pela equipe durante o desenvolvimento do Sistema Integrado de Segurança.

## 2. Integrantes e Responsabilidades

| Integrante | Responsabilidade |
|---|---|
| Integrante 1 | Desenvolvimento Front-End e prototipação no Figma. |
| Integrante 2 | Desenvolvimento Back-End e Chatbot. |
| Integrante 3 | Gerenciamento do GitHub, documentação, versionamento, organização e integração do projeto. |

## 3. Definições Técnicas

- O projeto será mantido em um único repositório GitHub.
- A documentação será armazenada na pasta `docs/`.
- Os módulos serão organizados em diretórios separados.
- O serviço de Machine Learning deverá ser desenvolvido em Python e disponibilizado por meio de uma API REST.
- As decisões de implementação deverão ser registradas e compartilhadas entre os integrantes.

## 4. Pendências de Definição

- Definir o responsável pelo desenvolvimento do serviço de Machine Learning.
- Escolher as tecnologias definitivas de Front-End e Back-End.
- Definir quais sensores ou fontes de dados serão utilizados.
- Definir os critérios de classificação e os níveis de risco.
- Estabelecer o cronograma de desenvolvimento e integração.
